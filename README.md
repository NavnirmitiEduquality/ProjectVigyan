# Project Vigyan

Project Vigyan is a multi-platform application consisting of:

- Backend: FastAPI
- Mobile App: Flutter for Para-Teachers
- Management Web App: Vue 3 + TypeScript
- Database: PostgreSQL
- Containerization: Docker

## Project Structure

- `backend/` - FastAPI backend
- `frontend/mobile/` - Flutter Para-Teacher application
- `frontend/web/` - Vue management web application
- `database/` - Database-related files and migrations
- `docs/` - Project documentation
- `scripts/` - Development and utility scripts
